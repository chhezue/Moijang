# API 응답 메시지 가이드

## 원칙

- 성공 메시지: 무엇이 완료됐는지 명확히 표현
- 실패 메시지: "~에 실패했습니다. 다시 시도해주세요." 형식 통일
- 환불 관련: Toss 처리 특성상 즉시 완료 표현 금지 → 소요 기간 안내 포함

---

## 인증

| 상황                         | 메시지                                           | 타입    |
| ---------------------------- | ------------------------------------------------ | ------- |
| 로그인 실패 (error 파라미터) | 로그인에 실패하였습니다                          | error   |
| 로그인 실패 (잘못된 정보)    | 아이디 또는 비밀번호가 올바르지 않습니다.        | error   |
| 인증코드 발송 성공           | 인증코드가 발송되었습니다.                       | success |
| 인증코드 발송 실패           | 인증코드 발송에 실패했습니다. 다시 시도해주세요. | error   |
| 이메일 인증 완료             | 이메일 인증이 완료되었습니다.                    | success |
| 이메일 인증 실패             | 인증에 실패했습니다. 다시 시도해주세요.          | error   |
| 중복 확인 실패               | 중복 확인에 실패했습니다. 다시 시도해주세요.     | error   |
| 회원가입 실패                | 회원가입에 실패했습니다. 다시 시도해주세요.      | error   |

## 공동구매

| 상황           | 메시지                                           | 타입    |
| -------------- | ------------------------------------------------ | ------- |
| 생성 성공      | 공구 신청이 완료되었습니다.                      | success |
| 생성 실패      | 공구 생성에 실패했습니다. 다시 시도해주세요.     | error   |
| 수정 성공      | 공동구매가 수정되었습니다                        | success |
| 수정 실패      | 공동구매 수정에 실패했습니다. 다시 시도해주세요. | error   |
| 가격 수정 성공 | 가격이 수정되었습니다.                           | success |
| 가격 수정 실패 | 가격 수정에 실패했습니다. 다시 시도해주세요.     | error   |
| 참여 완료      | 공동구매 참여가 완료되었습니다.                  | success |

## 환불 / 취소

> Toss 환불은 즉시 처리되지 않을 수 있으므로 "완료" 표현 사용 금지

| 상황                            | 메시지                                                              | 타입    |
| ------------------------------- | ------------------------------------------------------------------- | ------- |
| 참여 취소 성공 (참여자)         | 참여가 취소되었습니다. 환불은 영업일 기준 3~5일 내 처리됩니다.      | success |
| 참여 취소 성공 (총대 측)        | 참여가 취소되었습니다. 환불은 영업일 기준 3~5일 내 처리됩니다.      | success |
| 참여 취소 실패                  | 참여 취소에 실패했습니다.                                           | error   |
| 공구 취소 성공 (전체 환불)      | 공동구매가 취소되었습니다. 환불은 영업일 기준 3~5일 내 처리됩니다.  | success |
| 공구 취소 성공 (일부 환불 실패) | 공동구매가 취소되었습니다. 일부 환불은 수동으로 처리될 수 있습니다. | warning |
| 공구 취소 성공 (결제 없음)      | 공동구매가 취소되었습니다.                                          | success |
| 공구 취소 실패                  | 공동구매 취소에 실패했습니다.                                       | error   |

## 상태 변경 (총대)

| 상황                            | 메시지                                                                               | 타입    |
| ------------------------------- | ------------------------------------------------------------------------------------ | ------- |
| 주문 진행 실패                  | (백엔드 메시지 우선) \| 상태 변경에 실패하였습니다.                                  | error   |
| 배송 완료 처리 성공             | 배송 완료 처리되었습니다.                                                            | success |
| 배송 완료 처리 실패             | 배송 상태 변경에 실패했습니다.                                                       | error   |
| 배송 완료 + 픽업 정보 저장 실패 | 배송 완료 처리됐으나 픽업 정보 저장에 실패했습니다. 수정 버튼으로 다시 입력해주세요. | warning |
| 수령 정보 수정 성공             | 수령 정보가 수정되었습니다.                                                          | success |
| 수령 정보 수정 실패             | 수령 정보 수정에 실패했습니다.                                                       | error   |
| 공구 완료 성공                  | 공구가 완료되었습니다.                                                               | success |
| 공구 완료 실패                  | 공구 완료 처리에 실패했습니다. 다시 시도해주세요.                                    | error   |
